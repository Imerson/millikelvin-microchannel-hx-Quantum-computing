# Figure Scripts

The Python/ParaView scripts that generate the data-driven figures of the dissertation,
organised by the chapter each figure appears in. Every quantitative figure in the thesis
is machine-generated by one of these — no hand-drawn data.

**Requirements**: Python 3 with `numpy`, `pandas`, `matplotlib`; ParaView (`pvbatch`) for
the 3-D render only. **Paths**: the scripts were written against the dissertation folder
layout — `common.py` holds the shared `BASE` path and style; edit it (and the data paths
at the top of each script) to point at this repository's case folders before running.
The underlying data all lives in this repository: the six cases in
[`../1-Micro-channel heat exchanger/`](../1-Micro-channel%20heat%20exchanger/README.md),
the verification numbers in [`../2-Mesh_Independence study/`](../2-Mesh_Independence%20study/README.md),
and the benchmark model in [`../3-Sinter_vs_Microchannel_Comparison/`](../3-Sinter_vs_Microchannel_Comparison/README.md).

## Notes

- The geometry/unit-cell schematic (Fig. 2.1) and 3-D mesh view are ParaView compositions
  rather than scripted plots; `build_field3d_paraview.py` documents the scripted 3-D
  workflow used for the Chapter 3 render (the same approach applies to Fig. 2.1's view).
- In `plot_regime_map.py`, only the endpoints and T* ≈ 700 mK carry data — the sigmoid
  between them is a schematic interpolation, exactly as stated in the figure caption.
- The factorial data table (`comparison_hybrid.csv`) reports five-channel *model-level*
  resistance; system level = model level × 5/N_ch (`plot_resistance_vs_area.py` applies this).
